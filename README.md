# DominicsRestaurantProject
In this project we analyzed sales data from a my fictional Restaurant, that serves Brunch, Lunch and Dinner items.  We explored best- and worst-selling food items, tracked hourly and weekly trends, and broke down menu types by sales percentage. Data was queried in SQL, then visualized in Tableau dashboards for better decision-making
